支撑材料说明

本文件夹用于存放论文相关代码、原始数据、运行结果及辅助说明材料。为便于阅读者理解各文件用途，现对本文件夹中的主要内容说明如下。

一、原始数据文件说明

文件夹中的“订单信息.xlsx”“距离矩阵.xlsx”“客户坐标信息.xlsx”“时间窗.xlsx”为程序运行所需的原始输入数据文件。

上述四个 Excel 文件主要供“数据预处理.py”“q1.py”“q2.py”“q3.py”读取使用，用于完成订单清洗、客户需求聚合、车辆路径优化、绿色配送区限行调度以及动态事件重调度等计算过程。程序运行后，会将对应结果自动输出至“预处理结果”“问题一输出”“问题二输出”“问题三输出”等文件夹中。

需要说明的是，“订单信息.xlsx”“距离矩阵.xlsx”“客户坐标信息.xlsx”“时间窗.xlsx”本身不作为单独的结果支撑文件，其作用是为代码运行提供必要的原始数据输入。

二、代码文件说明

“数据预处理.py”用于完成原始订单数据清洗、缺失值插补、零需求节点剔除、客户需求聚合及基础统计输出。

“q1.py”用于求解问题一，即无绿色限行政策条件下的静态车辆路径优化问题，并输出问题一相关结果与图表。

“q2.py”用于求解问题二，即在绿色配送区限行政策约束下的车辆路径优化问题，并输出问题二相关结果与图表。

“q3.py”用于求解问题三，即在问题二最终方案基础上，针对动态事件进行实时重调度，并输出问题三动态调度结果。

三、结果文件夹说明

“预处理结果”文件夹存放数据清洗、缺失值插补、客户需求聚合和基础统计等预处理结果。

“问题一输出”文件夹存放问题一最终调度方案、路线明细、成本构成、鲁棒性仿真结果及相关图表。

“问题二输出”文件夹存放问题二最终调度方案、绿色配送区限行约束下的路线结果、成本构成、鲁棒性仿真结果及相关图表。

“问题三输出”文件夹存放动态事件场景设置、各阶段重调度结果、综合场景对比结果及相关修复日志。

四、AI 使用说明

“AI交互说明.pdf”为本队在建模、代码调试、结果核对和论文整理过程中使用 AI 辅助工具的情况说明。该文件主要用于说明 AI 在本次数学建模过程中的辅助作用，包括模型思路讨论、代码报错排查、结果一致性检查和论文表述优化等内容。

五、运行说明

若需要重新运行程序，请确保“订单信息.xlsx”“距离矩阵.xlsx”“客户坐标信息.xlsx”“时间窗.xlsx”与“数据预处理.py”“q1.py”“q2.py”“q3.py”位于同一文件夹下。随后可按以下顺序运行：

1. 运行“数据预处理.py”；
2. 运行“q1.py”；
3. 运行“q2.py”；
4. 运行“q3.py”。

程序运行完成后，对应结果会自动生成在“预处理结果”“问题一输出”“问题二输出”“问题三输出”文件夹中。
